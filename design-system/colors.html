Changelog · v0.2

Mint has been removed from the core palette.

Surfaces that previously used --mint should migrate to --sand. The palette now reads as a single warm-neutral paper with two blues and a single alert color — fewer hues, more intent.

06

Project step — status pills

Soft-tinted status colors used to label a project's position in the authoring pipeline. Each step pairs a pale background with a deeper foreground drawn from the same hue family — low contrast by design, so a table full of pills reads as quiet metadata, not alarms. These sit outside the core palette; they exist only for the step pipeline.
